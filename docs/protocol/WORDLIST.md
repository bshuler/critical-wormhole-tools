# Wormhole Code Wordlist

This document specifies the standard 256-word list used for generating wormhole codes.

## Design Criteria

Words were selected based on:

1. **Phonetic distinctness**: Words should sound different from each other
2. **Easy spelling**: Common words with predictable spelling
3. **Cross-language**: Pronounceable in multiple languages
4. **Positive/neutral**: Avoid negative or offensive connotations
5. **Length**: 3-8 characters preferred

## Usage

### Code Generation

```python
import random

def generate_code(nameplate, num_words=2):
    words = random.sample(WORDLIST, num_words)
    return f"{nameplate}-{'-'.join(words)}"

# Example: "7-guitar-sunset"
```

### Entropy

| Words | Bits of Entropy | Use Case |
|-------|-----------------|----------|
| 2 | 16 bits | Interactive (default) |
| 3 | 24 bits | Moderate security |
| 4 | 32 bits | High security |

### Language Notes

The wordlist is designed to be pronounceable in:
- English
- Spanish
- French
- German
- Portuguese
- Italian

Some words may need phonetic spelling when communicated:
- "aisle" (sounds like "I'll")
- "knight" (silent K)
- "subtle" (silent B)
