1. Various Link Types

Normal internal link Should be intercepted, navigate via wormhole
With query params Query params should be preserved
With hash Hash should be handled
Local hash only Should scroll, not navigate
javascript: void Should execute JS, not navigate
javascript: alert Should show alert
mailto: link Should open email client
tel: link Should offer to call
External https Should open in new tab
External http Should open in new tab
Protocol-relative Tricky! Might break things
Empty href Should reload current page?
No href attribute Not really a link
Relative ./path Should resolve correctly
Parent ../path Should go up one level
No leading slash Relative to current dir
