How it works

Enter a wormhole code like 7-guitar-sunset or a WNS address like mysite.wns. The site connects directly to the wormhole relay using WebSocket and WebRTC - everything runs in your browser.

Once connected, you can browse the remote site just like a normal website. Navigation, forms, and resources are all proxied through the encrypted wormhole connection.
